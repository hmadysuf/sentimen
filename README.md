# sentimen
program Flask lengkap yang mengimplementasikan tugas praktikum analisis sentimen terhadap kebijakan MBG (Makan Bergizi Gratis) dari komentar YouTube. Program ini mencakup:

    Crawling data dari YouTube Data API v3

    Preprocessing teks (cleaning, normalisasi, tokenisasi, handling negasi)

    Labeling sentimen (positif, negatif, netral) dengan lexicon-based

    Klasifikasi dengan Naïve Bayes dan SVM

    Evaluasi model (precision, recall, macro-F1, confusion matrix)

    Grafik distribusi sentimen

    Pengujian komentar baru yang telah divalidasi

    Dashboard web menggunakan Flask
